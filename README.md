# Information Retrieval Using TF-IDF

## GitHub Repository

https://github.com/vishali2403s-heey/Information_Retrieval.git

## Project Description

This project implements an Information Retrieval system using the TF-IDF (Term Frequency-Inverse Document Frequency) technique.

The system processes 10 text documents, calculates TF, IDF, and TF-IDF values, and ranks the documents based on their relevance.

## Source Code

The complete source code is available in the `index.py` file.

## Documents

The project contains 10 text documents in the `documents` folder.
